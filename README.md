# Collective Space - Co-Working Landing Page

A modern, responsive, and interactive landing page for a next-generation co-working space. This project is built entirely with **Bootstrap 5** without the use of any custom CSS, demonstrating a deep understanding of standard utility classes and built-in components.

## 🚀 Features

- **Fully Responsive Layout:** Flawlessly adapts to mobile, tablet, and desktop screens using the Bootstrap 5 Grid System and responsive utilities.
- **Interactive Workspaces (Tab Panels):** Users can dynamically switch between workspace details (Open Desk, Private Office, Meeting Room) without reloading the page, utilizing Bootstrap's `list-group` and JavaScript tab plugins.
- **Data Visualization:** Simulates live office occupancy rates using dynamic Bootstrap Progress Bars and Spinners.
- **Contextual Tooltips:** Provides extra information (e.g., ergonomic furniture details) efficiently using Bootstrap Tooltips.
- **Modern UI Components:** Includes a sticky navigation bar, breadcrumbs, alert banners, styled data tables with pagination, and interactive button groups.

## 🛠️ Technologies Used

- **HTML5:** Semantic and accessible markup.
- **Bootstrap 5.3:** For styling, grid layout, and interactive components.
- **Bootstrap Icons:** For scalable, modern, and clean vector iconography.

## 📂 Project Structure

This is a lightweight, frontend-only project.
- `index.html` - The main HTML file containing the entire layout, content, and component logic.
- `img/` - Directory containing high-quality, optimized image assets (AVIF format).
